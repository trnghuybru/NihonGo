# Brand asset generation

Tool: built-in image_gen (no CLI fallback).
Reference: existing momo-wave.png, then generated mascot head. Art direction: user-provided NihonGO brand reference.

## momo-head.png

Use case: logo-brand. Asset type: transparent PNG mascot head mark for the NihonGO mobile app. Reference: the attached Momo character. Create ONLY a clean cutout of Momo's happy head, matching the user's brand reference: orange tanuki chibi, round dark brown ears with cream inner ears, cream muzzle, brown eye patches, large warm brown eyes, small open smiling mouth, tiny blush marks. Head slightly tilted, both ears fully visible. Preserve exact character identity and polished soft 2D illustration style from reference. No body, no scarf, no paws, no typography, no container, no shadow, no background. Genuine transparent alpha canvas. Square composition, head centered with 6 percent clear padding, suitable for a compact wordmark alongside typeset NihonGO.

## nihongo-app-icon.png

Use case: logo-brand. Asset type: final square mobile app icon master, 1024x1024, full bleed opaque warm ivory #FFFBF7 background. Input: reference image is the exact mascot head identity to reuse faithfully. Compose one centered NihonGO brand icon matching the user's reference: orange happy tanuki head above the bold rounded sans-serif word NihonGO. Head occupies central upper 58 percent, text in lower middle; entire composition inside central 68 percent of canvas for safe launcher masking. Text exactly 'NihonGO', same baseline, 'Nihon' near-black #242323, 'GO' orange #FF8A26, bold friendly rounded geometric sans. Preserve tanuki facial features, tilted head, eyes, ears, smile, blush exactly from reference. No body, no scarf, no paws. Flat icon artwork, no perspective, no outer rounded square (OS masks it), no cast shadow, no border, no mockup scene, no extra words. Clean opaque ivory square reaching all edges.

Generated outputs were inspected and resized with macOS sips for the app. No changes to the existing four learning poses.
