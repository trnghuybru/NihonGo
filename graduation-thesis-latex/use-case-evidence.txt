Important distinctions preserved:
- Scoring definitions: backend/writing/rubric.py:RUBRIC, validate_assessment; backend/speaking/evaluation_ai.py:CRITERIA.
- Email registration also requires name and phone; registration is finalized only after code verification.
- Recovery does not reveal whether an account exists; successful reset revokes old sessions.
- Learning preference conflicts use version checking.
- Flashcard ratings are self-assessments, not automatically measured proficiency.
- Shadowing comprehension uses a fixed set of 5 questions; response choices are frontend state.
- Speaking evaluation requires a completed session and at least 3 nonempty user replies for scoring.
- Speaking feedback is transcript-based and does not score pronunciation.
- Local Supertonic experiment availability is conditional, not a production guarantee.
- Reading grading uses source answers; AI explanation does not replace the answer key.
- Writing resubmission creates a new submission; reevaluation updates the existing assessment.
- Shared game lobbies are distinct from free-conversation/matchmaking data tables.
