Hệ thống NihonGO được xây dựng bằng React Native cho ứng dụng di động, React Native Web cho giao diện web và Flask cho backend. PostgreSQL lưu trữ dữ liệu học tập, trong khi các mô hình AI hỗ trợ hội thoại, nhận xét bài làm và nhận dạng ký tự viết tay. Bảng~\ref{tab:technologies-used} trình bày các công nghệ chính và vai trò của chúng trong hệ thống.
